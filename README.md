# Lostqn — Personal Portfolio

A responsive, black-and-gray personal portfolio website for staff and management experience. It uses plain HTML, CSS, and JavaScript, so you don't need a framework or build tools.

## Preview locally
1. Download and unzip the project.
2. Open `index.html` in a web browser.

## Personalize it first
Edit `index.html` in any text editor:
- Change `Lostqn`, `@yourdiscord`, pronouns, bio, and timezone.
- Replace placeholder server names, roles, dates, and descriptions in the **Staffing** tab.
- Update the project cards with work you actually did.
- Replace the Discord, GitHub, and email links.
- Replace `assets/avatar.svg` with your own image, or change the avatar image path in the HTML. If using a PNG, for example, save it as `assets/avatar.png` and change `src="assets/avatar.svg"` to `src="assets/avatar.png"`.

Keep private staff logs, personal data, and screenshots shared without permission out of the public site.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `lostqn-portfolio` (or another name).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder. Make sure `index.html` is at the repository root, not inside another nested folder.
3. Open the repository's **Settings** tab.
4. Select **Pages** in the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Set branch to `main` and folder to `/(root)`, then save.
7. Wait a few minutes. The published URL will normally look like `https://YOUR-GITHUB-USERNAME.github.io/lostqn-portfolio/`.

If your repository is named exactly `YOUR-GITHUB-USERNAME.github.io`, GitHub Pages can publish at the root URL instead. Replace the placeholder username with your GitHub username.

## Files
- `index.html` — page content and tabs
- `style.css` — design, layout, and responsive styles
- `script.js` — clickable tabs and keyboard navigation
- `assets/avatar.svg` — placeholder avatar artwork
